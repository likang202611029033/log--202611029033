第 1 章 · 基础篇

C++ 简介与环境搭建

认识这门语言，装好第一个编译器与开发工具。

本章学习目标
  • 了解 C++ 的历史、特点与主要应用领域
  • 理解「编译器」在程序开发中的作用
  • 完成 Windows 下的编译环境搭建（推荐 Visual Studio Community 或 MinGW）

1.1 C++ 是什么

C++ 是一门静态类型、编译型的通用程序设计语言，由 Bjarne Stroustrup 于 1979 年在 C 语言基础上扩展而来。它同时支持面向过程与面向对象两种编程范式，并对底层硬件有很强的控制力。

今天 C++ 被广泛用于：操作系统与驱动、游戏引擎（Unreal、Unity 底层）、高频交易、嵌入式系统、浏览器内核、图形图像处理等对性能要求极高的领域。

1.2 开发环境的组成

一个完整的 C++ 开发环境由两部分组成：

  • 编译器：把人写的 .cpp 源代码翻译成机器可执行的二进制程序。Windows 上常用 MSVC（微软）或 g++（MinGW）。
  • IDE / 编辑器：写代码、管理工程、一键编译调试的图形界面。新手推荐 Visual Studio Community，免费且集成度高。
推荐方案（Windows 新手） 下载并安装 Visual Studio Community（微软官网免费），安装时勾选「使用 C++ 的桌面开发」工作负载，它会自动装好编译器、调试器和标准库，无需额外配置。

1.3 编译过程一览

一段 C++ 代码从文本到可运行程序，大致经历四个阶段：预处理 → 编译 → 汇编 → 链接。初学阶段只需记住：源代码 (.cpp) 经过编译器处理后，生成一个 .exe 可执行文件。

常见坑 安装 Visual Studio 时如果只装了主程序而没勾选「使用 C++ 的桌面开发」，新建项目时会找不到 C++ 选项。这时可以通过「Visual Studio Installer」补充安装。

1.4 本章小结

  • C++ 是一门高效、多范式的编译型语言。
  • 开发环境 = 编译器 + IDE，新手推荐 Visual Studio Community。
  • 源代码必须经过编译才能变成可运行的程序。

第 2 章 · 基础篇

第一个 C++ 程序

逐行读懂 Hello World，理解每个符号的作用。

本章学习目标
  • 写出并运行第一个 C++ 程序
  • 理解 #include、main、cout 的含义
  • 掌握注释的写法与基本代码规范

2.1 Hello, World!

// 第一个 C++ 程序
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

2.2 逐行解释

代码含义
// 第一个 C++ 程序单行注释，编译器会忽略它。/* ... */ 可写多行注释。
#include <iostream>引入输入输出头文件，之后才能使用 cin / cout。
int main()主函数，程序永远从这里开始执行。每个 C++ 程序有且只有一个 main。
std::cout标准输出对象，<< 是「插入符」，把后面的内容送到屏幕。
std::endl输出一个换行并刷新缓冲区。
return 0;告诉操作系统程序正常结束。

2.3 using namespace std 的习惯

频繁写 std:: 比较啰嗦，实践中常在文件开头加一行：

#include <iostream>
using namespace std;   // 引入标准库命名空间

int main() {
    cout << "你好，C++！" << endl;
    return 0;
}
代码规范小提示 每条语句以分号 ; 结束；花括号 { } 通常单独占一行；适当缩进（4 个空格）让代码可读。

2.4 本章小结

  • 程序入口是 main()。
  • 输出文本用 cout << ...，字符串必须放在双引号内。
  • 注释不会被编译，用来给人读。

第 3 章 · 基础篇

数据类型与变量

程序用变量存储数据，数据有不同的类型。

本章学习目标
  • 掌握基本数据类型：int、double、char、bool
  • 学会声明变量、赋值与初始化
  • 理解常量 const 与标识符命名规则

3.1 什么是变量

变量是内存中的一块命名区域，用来存放程序运行时会变化的数据。声明变量时必须告诉编译器它的类型。

3.2 基本数据类型

类型含义示例
int整数int age = 20;
double双精度浮点数double price = 9.9;
float单精度浮点数float f = 1.5f;
char单个字符char c = 'A';（单引号）
bool布尔值bool ok = true;

3.3 声明与初始化

#include <iostream>
using namespace std;

int main() {
    int age = 18;          // 声明并初始化
    double height;        // 先声明
    height = 1.75;           // 后赋值
    char grade = 'A';
    bool pass = true;

    cout << age << endl;
    cout << height << endl;
    return 0;
}

3.4 常量 const

用 const 修饰的变量一旦赋值就不能修改，常用于保存固定参数，避免被误改：

const double PI = 3.14159;
// PI = 3.14;  // 编译报错：不能给 const 变量赋值
命名规则 变量名只能由字母、数字、下划线组成，不能以数字开头，区分大小写。习惯上变量用小写单词（如 studentAge），常量全大写（如 MAX_SIZE）。

3.5 本章小结

  • 变量必须先声明类型再使用；未初始化的变量值是不确定的。
  • 常用类型：int / double / char / bool。
  • const 定义只读常量。

第 4 章 · 基础篇

运算符与表达式

用运算符把变量和常量组合成表达式，完成计算。

本章学习目标
  • 掌握算术、赋值、关系、逻辑运算符
  • 理解运算符优先级与整数除法的陷阱
  • 能写出常见的数值表达式

4.1 算术运算符

运算符含义示例
+ - * /加、减、乘、除a + b
%取余（取模）7 % 3 == 1
++ --自增、自减i++
整数除法陷阱 两个 int 相除，结果仍是 int，小数部分被直接丢弃：7 / 2 == 3，不是 3.5。想要小数结果，至少有一个操作数是 double：7.0 / 2 == 3.5。

4.2 赋值与复合赋值

int x = 10;
x += 5;   // 等价 x = x + 5;  现在 x = 15
x *= 2;   // x = 30
x %= 7;   // x = 2

4.3 关系与逻辑运算符

类别运算符结果
关系> >= < <= == !=true / false
逻辑&&（与） ||（或） !（非）true / false
int age = 20;
bool isAdult = age >= 18;          // true
bool canDrive = (age >= 18) && (age < 70);  // true
注意区分 赋值是 =，判断相等是 ==。写成 if (x = 5) 在 C++ 中是合法但危险的写法，初学者务必看清楚。

4.4 本章小结

  • 注意整数除法会截断小数。
  • 关系/逻辑运算结果是 bool 值。
  • 牢记 = 与 == 的区别。

第 5 章 · 基础篇

输入与输出

让程序能接收用户输入，并把结果打印出来。

本章学习目标
  • 使用 cin 读取键盘输入
  • 使用 cout 输出多个值并换行
  • 理解顺序结构程序的执行流程

5.1 输出 cout

用 << 连续拼接多个输出项：

int a = 3, b = 4;
cout << "a + b = " << (a + b) << endl;
// 输出：a + b = 7

5.2 输入 cin

用 >> 从键盘读取数据，存入变量：

#include <iostream>
using namespace std;

int main() {
    int score;
    cout << "请输入你的分数：";
    cin >> score;
    cout << "你输入的分数是：" << score << endl;
    return 0;
}

5.3 顺序结构

程序默认从上到下依次执行每条语句，这就是顺序结构。它是三种基本程序结构中最简单的一种。

小练习 写一个程序：输入两个整数，输出它们的和、差、积。

5.4 本章小结

  • 输出用 cout <<，输入用 cin >>。
  • 语句按书写顺序自上而下执行。

第 6 章 · 控制流篇

分支语句

让程序根据条件走不同的路。

本章学习目标
  • 掌握 if / else if / else 的用法
  • 掌握 switch 多分支语句
  • 能写出成绩判定、奇偶判断等典型分支逻辑

6.1 if 语句

int age;
cin >> age;

if (age >= 18) {
    cout << "成年" << endl;
} else {
    cout << "未成年" << endl;
}

6.2 多分支 else if

int score;
cin >> score;

if (score >= 90)      cout << "A" << endl;
else if (score >= 80) cout << "B" << endl;
else if (score >= 60) cout << "C" << endl;
else                       cout << "D" << endl;

6.3 switch 语句

当判断条件是一个整数/字符的离散取值时，用 switch 更清晰：

int day;
cin >> day;
switch (day) {
    case 1: cout << "星期一"; break;
    case 2: cout << "星期二"; break;
    default: cout << "其它";
}
别忘了 break 每个 case 末尾的 break 用来跳出 switch。漏掉它，程序会继续「穿透」执行下一个 case，这是初学者最常见的 bug。

6.4 本章小结

  • 二选一比用 if-else，多选一用 else if 链或 switch。
  • switch 每个分支记得写 break。

第 7 章 · 控制流篇

循环语句

让计算机替你重复做同一件事。

本章学习目标
  • 掌握 while、do-while、for 三种循环
  • 理解 break 与 continue 的区别
  • 能写出累加、求和、九九表等经典程序

7.1 while 循环

int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}
// 输出：1 2 3 4 5

7.2 for 循环

已知循环次数时，for 循环最紧凑（初始化、条件、步进写在一行）：

// 求 1 到 100 的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
cout << sum << endl;   // 5050

7.3 do-while 循环

循环体至少执行一次（先执行后判断）：

int n;
do {
    cout << "输入一个正整数：";
    cin >> n;
} while (n <= 0);

7.4 break 与 continue

  • break：立即跳出整个循环。
  • continue：跳过本次剩余语句，直接进入下一次循环。
经典练习 用双层 for 循环打印九九乘法表：外层控制行 i 从 1 到 9，内层控制列 j 从 1 到 i。
死循环 循环条件永远为真、又没有 break 跳出，程序就会停不下来。写循环时务必确认循环变量会朝「条件不成立」的方向变化。

7.5 本章小结

  • 三种循环可互相转换：计数用 for，条件用 while，至少执行一次用 do-while。
  • break 跳出循环，continue 跳到下一轮。

第 8 章 · 数据组织篇

数组与字符串

用一个名字管理一批同类型数据。

本章学习目标
  • 掌握一维数组的声明、遍历与下标访问
  • 了解二维数组的基本用法
  • 会使用 string 类处理字符串

8.1 一维数组

int scores[5] = {90, 85, 78, 92, 88};

// 下标从 0 开始：scores[0] 是第一个元素
for (int i = 0; i < 5; i++) {
    cout << scores[i] << endl;
}
下标越界 C++ 不检查数组下标是否越界。访问 scores[5]（长度为 5 的数组，合法下标是 0~4）不会报错，但会读到垃圾数据甚至导致程序崩溃。

8.2 二维数组

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
cout << matrix[1][2];   // 6

8.3 string 字符串

使用标准库 string 可以方便地处理文本，需要包含头文件 <string>：

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1 = "Hello";
    string s2 = "C++";
    string s3 = s1 + " " + s2;   // 拼接
    cout << s3 << endl;            // Hello C++
    cout << s3.size() << endl;     // 长度 9
    return 0;
}

8.4 本章小结

  • 数组下标从 0 开始，长度为 n 的数组合法下标是 0 ~ n-1。
  • 字符串优先使用 string，而不是裸字符数组。

第 9 章 · 数据组织篇

函数

把一段功能封装起来，反复调用。

本章学习目标
  • 掌握函数的定义、声明与调用
  • 理解参数传递与返回值
  • 了解函数重载与递归的概念

9.1 为什么需要函数

函数把一段完成特定任务的代码包装起来，起个名字。好处：避免重复代码、结构清晰、便于调试与多人协作。

9.2 定义与调用

// 返回值类型  函数名(参数列表) { 函数体 }
int add(int a, int b) {
    return a + b;
}

int main() {
    int r = add(3, 4);
    cout << r << endl;   // 7
    return 0;
}

9.3 值传递

C++ 默认把实参的值拷贝一份给形参，函数内部对形参的修改不会影响外部变量：

void tryChange(int x) {
    x = 100;   // 只改了副本
}
// main 中调用 tryChange(n) 后，n 本身不变

9.4 函数重载

同一个函数名，参数列表不同，可以定义多个版本：

int   max(int a, int b);
double max(double a, double b);   // 合法重载
本章练习 写一个函数 int factorial(int n)，返回 n 的阶乘（1×2×...×n），再用 main 调用它输出 5! 的结果。

9.5 本章小结

  • 函数 = 返回类型 + 函数名 + 参数列表 + 函数体。
  • 默认参数是值传递，函数内改形参不影响外部。

第 10 章 · 进阶篇

指针与引用

C++ 最重要也最难的一关：直接操作内存地址。

本章学习目标
  • 理解「内存地址」与指针的概念
  • 掌握指针的定义、取地址与解引用
  • 理解引用的本质及与指针的区别

10.1 内存与地址

每个变量在内存中都占据一块位置，并有一个编号，即地址。运算符 & 可以取出变量的地址：

int a = 10;
cout << &a << endl;   // 输出类似 0x61fe14 的地址

10.2 指针变量

指针就是存放地址的变量。类型 * 表示「指向该类型的指针」：

int a = 10;
int* p = &a;     // p 保存了 a 的地址

cout << *p << endl;  // 解引用：通过地址读出 a 的值 10
*p = 20;          // 通过指针修改 a
cout << a << endl;   // 20

10.3 引用

引用是变量的「别名」，定义时必须初始化，之后它就和原变量指向同一块内存：

int a = 10;
int& ref = a;    // ref 是 a 的别名
ref = 99;
cout << a << endl;   // 99，a 也被改了

引用最常见的用途是让函数能修改外部变量，或避免拷贝大对象：

void swap(int& x, int& y) {
    int t = x; x = y; y = t;
}
// 调用 swap(a, b) 后，a、b 的值真的被交换了
新手常见错误 ① 指针未初始化就使用（野指针）；② 解引用空指针 nullptr；③ 引用定义时忘了初始化。这三种都会导致程序崩溃。

10.4 本章小结

  • 指针存地址，* 用于解引用。
  • 引用是变量别名，函数参数用引用可修改实参。

第 11 章 · 进阶篇

类与对象入门

走进面向对象编程的大门。

本章学习目标
  • 理解「类」与「对象」的关系
  • 学会定义类、声明成员变量与成员函数
  • 了解构造函数与访问控制 public / private

11.1 从结构体到类

面向对象思想把数据和操作数据的方法打包在一起。类是蓝图，对象是按蓝图造出的具体实例。

11.2 定义一个类

#include <iostream>
using namespace std;

class Student {
public:                    // 以下成员对外可访问
    // 成员变量
    string name;
    int age;

    // 成员函数
    void introduce() {
        cout << "我叫" << name << "，今年" << age << "岁" << endl;
    }
};

int main() {
    Student s;             // 创建对象
    s.name = "小明";
    s.age  = 20;
    s.introduce();       // 调用成员函数
    return 0;
}

11.3 构造函数

构造函数在对象创建时自动调用，常用于初始化成员。它与类同名、没有返回值：

class Student {
public:
    string name;
    int age;
    Student(string n, int a) {   // 构造函数
        name = n;
        age  = a;
    }
};

// 创建对象时直接传参
Student s("小红", 19);

11.4 public 与 private

  • public：外部可以直接访问。
  • private：只能在类内部访问，外部需通过公开的成员函数操作。这就是封装。
学完本教程后可以继续 继承与多态、运算符重载、STL 容器（vector / map）、模板、文件输入输出——这些是 C++ 进阶内容，建议在熟练掌握本教程 11 章后再深入。

11.5 课程总结

恭喜你完成全部 11 章！回顾一下学习路径：

  1. 环境与第一个程序 → 2. 数据与运算 → 3. 输入输出与控制流 → 4. 数组与函数 → 5. 指针、引用与面向对象入门。

编程是一门实践性极强的技能，建议每学一章就在编译器里把代码敲一遍、改一改，观察结果变化。
