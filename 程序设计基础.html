1. 什么是程序

先搞清楚：我们到底在学什么。

程序，就是写给计算机的一份「步骤清单」。你把一件事拆成一步一步明确的动作，计算机照着做，这就是运行程序。

计算机本身只懂 0 和 1，直接写 0101 太累，于是人们发明了接近人类语言的编程语言（C、Python 等），再由编译器/解释器把它翻译成机器能懂的指令。

第一个程序：Hello World

/* 经典的第一个程序 */
#include <stdio.h>
int main() {
    printf("Hello, World!\n");  // 在屏幕上打印一行字
    return 0;
}
运行一下
点击「运行」查看程序输出…
要点：程序 = 给计算机的步骤清单；计算机只懂二进制，编程语言靠编译器/解释器翻译；学编程就是学会把问题拆成一步步明确的动作。

2. 变量与数据类型

变量就是贴了标签的盒子，用来存放数据。

写程序时先在内存里放一个「盒子」，起个名字（变量名），再把数据放进去。不同种类的数据要用不同的盒子：

  • int 整数：18、100、-5
  • float 小数：1.75、3.14
  • char 字符：'A'、'好'
  • bool 真假：true / false

变量名要遵守规则：用字母或下划线开头，后面可以跟字母、数字，不能含空格或特殊符号；起有意义的名字（用 age 而不是 a）。

int age = 18;          // 整数：年龄
float height = 1.75;   // 小数：身高（米）
char grade = 'A';      // 字符：等级
动手试：输入你的年龄
点击「运行」查看…
要点：变量 = 命名的存储位置；先定类型再赋值；int 整数、float 小数、char 单个字符；变量名要见名知意、不能以数字开头。

3. 运算符与表达式

程序做计算，全靠运算符。

四则运算 + - * / 很好懂，注意两个坑：

  • 整数除法会丢掉小数：10 / 3 结果是 3，不是 3.33
  • % 是取余数，判断奇偶、分组都靠它：10 % 3 = 1
int a = 10, b = 3;
a + b;   // 13
a / b;   // 3 （整数除法）
a % b;   // 1 （余数）
动手试：填两个数，看六种运算结果
点击「运行」查看…
要点：整数除法丢掉小数；% 取余数常用于判断奇偶；i++ 等价 i=i+1，+= 是累加简写；运算顺序和数学一样，括号最优先。

4. 条件判断 if / else

让程序学会「看情况办事」。

程序可以根据条件选择走哪条路：条件成立走这条路，不成立走另一条。

if (score >= 60) {
    printf("及格了\n");
} else {
    printf("继续加油\n");
}
动手试：拖动分数，看程序怎么判断

点击「运行」查看…
要点：if 判断条件，成立走 if 分支，不成立走 else；多级判断用 else if；比较符 > >= < <= == != 别忘了两个等号 ==。

5. 循环 for / while

重复的事，交给循环。

知道重复几次用 for；不知道次数、条件成立就继续用 while。比如累加 1 到 n：

int sum = 0;
for (int i = 1; i <= n; i++) {
    sum = sum + i;   // 每轮把 i 加进 sum
}
动手试：设置循环次数，观察累加过程
5
点击「运行」查看…
要点：知道次数用 for，不确定次数用 while；循环三要素——初值、条件、步进；break 提前跳出、continue 跳过本轮；小心条件写错导致死循环。

6. 函数

把一段功能打包，起个名字，随用随取。

函数 = 输入 → 加工 → 返回结果。写一次，到处调用，不用重复粘贴代码。

int square(int x) {
    return x * x;
}
int r = square(5);   // r = 25
动手试：调用 square(x)
点击「运行」查看…
要点：函数 = 输入参数 → return 结果；可以有多个参数；返回值用 return，不写就没有返回值；把重复的逻辑封装成函数，主程序才清爽。

7. 数组

一排编号的盒子，数据排队存放。

数组用下标存取数据，下标从 0 开始：第 0 个、第 1 个……批量数据就该用它，而不是各起一个变量。

int scores[5] = {85, 90, 78, 92, 88};
scores[0]   // 85
scores[4]   // 88

要点：数组是一排连续存放的数据；下标从 0 开始；用循环遍历数组求和、找最大最小是最常见的用法。
